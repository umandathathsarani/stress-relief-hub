# Stress Relief Hub 🧘‍♂️

A modular web application featuring a collection of interactive mini-games designed for relaxation and stress relief. 

## Project Overview
This project serves as a centralized hub for lightweight, browser-based games. It is built with vanilla web technologies and relies on a strong Object-Oriented architecture to manage game states and rendering logic efficiently.

## Features
* **Modular Architecture:** Each mini-game inherits from a core `Game` class, ensuring clean, maintainable code.
* **Interactive UI:** Smooth transitions and a calming interface designed for a seamless user experience.
* **Growing Collection:** Currently planning to scale up to 8 distinct physics, canvas, and DOM-based mini-games.

## Tech Stack
* HTML5 / CSS3
* Vanilla JavaScript (ES6 Modules)
* HTML5 Canvas API / Web Audio API
